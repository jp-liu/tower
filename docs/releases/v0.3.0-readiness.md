## Rollback state

No external state changed, so there is currently no npm, tag, GitHub Release,
or remote-branch rollback to perform. If this local candidate is abandoned,
use normal `git revert` commits for `c785ac7` and `8d1d732`; do not rewrite

stopping 0.3, restoring the pre-upgrade 0.2 backup, and reinstalling the prior
0.2 package without opening the upgraded database from 0.2.
