Tower Unattended Message Relay

RECORD · PARK · RESUME — send/receive outsourced to external gateways

Three glue jobs
Record the question (write /harness) · park the task (PAUSED) · resume on reply (inject into the live terminal). Never touches send/receive.
Token [[tower:task=id]]
Every outbound must carry it; the reply brings it back so the gateway attributes it to the task. No token = unattributable reply = task stuck forever.
Four tools at a glance
ask = record + park (no send) · notify = record (no send/no park) · push = send + record (one-stop) · reply_to_ask/relay = inbound resume.
